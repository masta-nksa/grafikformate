Eine Rastergrafik ist nur eine lange Folge von Bits. Der kurze Header sagt, wie die Bits zu lesen sind: wie breit und hoch das Bild ist und wie viele Bits zu einem Pixel gehören (Farbtiefe). Danach folgen die Pixel – von links oben nach rechts unten, Zeile für Zeile, so wie man liest.

Farbmodelle

  • Graustufen: Der Wert eines Pixels ist seine Helligkeit. Bei 1 Bit gilt 0 = schwarz, 1 = weiss.
  • RGB: Die Bits eines Pixels werden auf Rot, Grün und Blau verteilt (z.B. 3 Bit: R G B, 24 Bit: 8 Bit pro Kanal). Ist die Farbtiefe nicht durch 3 teilbar, erhält Grün (und dann Rot) ein Bit mehr.
  • Automatisch: 1–2 Bit Graustufen, ab 3 Bit RGB.
  • Farbpalette: Das Pixel speichert nur die Nummer (den Index) einer Farbe in einer Tabelle – so macht es das GIF-Format.

Bedienung

  • Bits können direkt eingetippt oder eingefügt werden. Leerzeichen und Zeilenumbrüche werden ignoriert.
  • In der Hex-Ansicht steht jede Ziffer für 4 Bits (F = 1111).
  • Fahren Sie über ein Pixel, um seine Bits und Farbwerte zu sehen. Mit Zeichnen lassen sich Pixel einfärben – die Bits ändern sich mit.
  • Schraffierte Pixel haben (noch) keine Daten: Es fehlen Bits.
  • Link teilen speichert das aktuelle Bild in einem Link. Lehrpersonen können daraus eine Aufgabe mit Zielbild machen.

Text → Bits

Jedes Zeichen wird mit seinem ASCII-Code (8 Bit) gespeichert. Umlaute benötigen in UTF-8 zwei Bytes.
